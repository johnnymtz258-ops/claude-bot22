v10.2 SMART AUTOPILOT — CHANGE NOTES

DISCOVERY / SIGNALS
- Fresh-launch scanner tier for very new Solana coins.
- Re-entry/consolidation setup detection using stored observation history.

MANUAL COIN INPUT

- /track /tracked /untrack added.

PERSISTENCE
- Shared DB: ~/Library/Application Support/FomoBot/fomo_master.db
- First-launch recovery of active positions from older sibling v9_signals.db files.

AUTOPILOT
- Paper autopilot for no-money testing.
- Optional real Solana execution through Jupiter with local signing.

- Real fresh-launch auto buys disabled by default.
- Trade-size, max-open, buys/day, daily realized-loss, SOL reserve, price impact, anti-chase, hard safety, TP1/TP2, stop, trailing, liquidity and time-exit controls.
- If real autopilot is turned off while an auto position remains open, normal Telegram TP/risk alerts continue.
